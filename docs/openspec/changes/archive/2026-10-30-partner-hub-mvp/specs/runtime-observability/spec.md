# 本地运行与可观测规格

## Purpose

规定本地 MVP 的启动、退出、资源边界及可测量交付口径，让演示和故障实验能够复现并解释实际状态，同时明确单节点中间件及未保存首轮的限制，不将设计参数、成功样本或Broker确认扩展为未经实测的可靠性承诺。

## ADDED Requirements

### Requirement: 控制台使用有来源与新鲜度的真实观测
中台 MUST 通过固定后端白名单查询缓存读取Prometheus指标，包含业务全链路、逐实例进程与池、MySQL/Redis/Kafka资源及消费积压；MUST 显示来源、采样时间和不可用/过期状态，不把缺失当零。页面刷新 MUST 不直接触发中间件探测；共享gauge不得跨实例相加，histogram按bucket合并后计算分位。不存在的宿主/JVM采集 MUST 显示未采集。Grafana复用既有指标源，不新增消息标识高基数标签。

#### Scenario: 部分采样失败
- **WHEN** Prometheus或某依赖不可达，或者指标不存在
- **THEN** 显示失败范围及最近成功时间，旧值明确标为过期，无历史样本则不可用，其他实例或指标仍可查看

### Requirement: 最近诊断与持久业务历史分开
系统 MUST 有界保留每实例最近1000条脱敏诊断，标明实例、启动标识、覆盖范围和重启清空边界；包括校验拒绝、限流、接管未确认和关键运行异常。持久成交/投递/人工历史 MUST 继续以MySQL为准。诊断查询 MUST 使用本地鉴权和固定实例地址，返回部分失败；不得记录完整业务载荷、凭据或任意原始错误。

#### Scenario: 拒绝请求未生成持久成交
- **WHEN** 校验或额度检查拒绝，或接管未确认
- **THEN** 诊断提供requestId与有限原因；只有可信解码后的标识用于关联，未确认不改写为明确未发送

#### Scenario: 重启或实例不可达
- **WHEN** 一个实例重启或诊断查询失败
- **THEN** 显示bootId/内存保留范围及失败实例，空结果不冒充全部实例无异常，原有持久业务记录仍可查询

### Requirement: 本地环境可重复启动且迁移不隐式重置
本地部署 MUST 包含两个同程序hub、三个Mock、入口代理、MySQL/Redis/Kafka及指标组件；迁移在放行readiness前完成，不由两个实例并发重置数据库。凭据外置，Mock存储隔离，演示重置为独立显式操作；中间件维持单节点边界。

#### Scenario: 空环境启动与保留数据重启
- **WHEN** 按文档在空环境启动，或保留卷重启
- **THEN** schema准备后才接入请求，重启不清除关系/记录或重复初始化破坏数据，实际启动检查可复现

### Requirement: 多实例退出仅恢复已保存责任
实例退出 MUST 先停止新首发/领取并在有界预算内保存已知结果；存活实例继续处理新输入，已暂存正常记录和已提交异常任务由相应协调恢复。未保存首轮及中间件主机/磁盘故障 MUST 不承诺零丢失；liveness与分项readiness分别表达。

#### Scenario: 停止一个应用实例
- **WHEN** 双实例运行时退出一个实例，其存在已接管任务/待归档快照
- **THEN** 存活实例处理新请求，已保存责任按租约继续，退出窗口和UNKNOWN记录可解释

### Requirement: 容量与日志指标有界可解释
入口、平台、数据库回源/移交/归档/恢复/查询及客户端队列 MUST 有明确预算；归档达到高水位停止新输入、低水位恢复，已接管数据不因过载删除。指标 MUST 区分首发、归档、恢复与外部消费；日志不记录敏感全文，指标标签不使用msgId/UID/traceId等高基数字段。

#### Scenario: 归档变慢与资源耗尽
- **WHEN** 数据库归档持续延迟造成积压达到配置高水位
- **THEN** 新入口明确拒绝，已有快照保留并显示条数/字节/最老时长，恢复至低水位后才重开

### Requirement: 首次交付性能按全输入及平台边界实测
正常负载且外部正常时，各目标平台从接入到首次交付 MUST 分别P99≤5秒，包含排队、路由与外发；平台2终点为Broker确认，不包含消费展示。报告 MUST 同时报机器、QPS、持续时间、消息大小、缓存冷热、全输入cohort、失败/未完成数及资源，不只统计成功样本。

#### Scenario: 正常与故障负载分开报告
- **WHEN** 运行正常、突发或平台故障/缓存冷启动实验
- **THEN** 按已声明条件分别给出首发及归档/恢复时延和失败数，不用正常P99结论掩盖故障、未完成或消费者积压
