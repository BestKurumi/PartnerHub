# MVP 验收摘要

日期：2026-10-30。已确认范围内的 34 项任务完成，功能与本轮页面修订验收通过，未发现未关闭的重要审查问题。本文用于公开交付查阅；各批次验证有重叠，数量不能相加作为功能覆盖率。

## 已覆盖的功能

| 范围 | 实际验证 |
|---|---|
| 绑定与路由 | 双平台绑定、冲突与匹配 UID 解绑、解绑仅影响新消息、旧任务固定 UID、NO_ROUTE 不补推；有真实 MySQL/Kafka 集成及端到端历史证据 |
| 消息分发 | A HTTP 实收、B Kafka Broker 确认与独立消费落库；暂停后恢复消费；双平台八字段、类型与时间精度 |
| 异常与恢复 | 历史故障矩阵覆盖拒绝、保存后超时、通道故障、回源故障、实例退出、有限重试与人工恢复；允许确认不明及实际重复 |
| 查询与观测 | 持久查询、筛选与分页、最近诊断、指标缺失/过期与历史图表、实例对比及单实例详情 |
| 消息耗时图 | 按 msgId/Trace ID 查询、显式选择消息、并发尝试与间隔、详情、分页、旧响应隔离；只显示已有时间事实 |
| 页面验收修订 | 人工恢复区编号与命令语义、上游编号分列和中文确认标签、A/B 字段层级、B 消费状态卡；用户已确认上下游展示及 B 暂停/恢复闭环通过 |
| 数据保留 | 历史保留卷重启验证；本轮滚动更新后消息、绑定、A/B 实收各 20 条样本保留，20 条消息详情可读；抽样不代表全库逐行核对 |

## 已知边界与未验证范围

- 本机演示令牌不是生产用户认证；绑定客户号有格式校验，未接入真实客户存在性、归属及授权核验。
- B 投递成功仅表示 Broker 确认；UNKNOWN 可能已送达，恢复可能重复实收；未保存首轮结果及单节点中间件故障不承诺零丢失。
- 耗时图基于已有事件和尝试时间，未采集内部阶段不补造，不等于完整分布式 Span 树。Trace ID 不保证唯一；刷新选中消息后优先恢复 msgId，不恢复原 Trace 匹配列表。
- 上游测试记录保存在当前页面内存，刷新清空；持久消息与绑定仍从数据库查询。诊断日志是逐实例有界内存记录，重启可清空。
- Docker 与本地源码两种启动方式均有实现和验证记录；未完成 Windows、Linux 和不同 CPU 架构的逐系统实机验收，也未承诺全套离线安装。
- 历史负载结果仅适用于当时本机条件；本次没有持续压测、生产容量评估、生产身份体系或中间件主机/磁盘容灾验证。
